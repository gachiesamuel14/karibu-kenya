# Karibu — dating for Kenya

Installable Progressive Web App + Capacitor shell for Android.

**Live:** https://karibu-kenya-0k91.netlify.app

## Install on phone

Open the live site → **Install app** / Add to Home Screen.

Full steps: [APP-INSTALL.md](APP-INSTALL.md)

## Features

- Profiles (18+)
- GPS + county filters
- Like / match / chat (demo data on device)
- Report flow
- PWA install prompt

## Android APK

```bash
npm install
npx cap add android
npx cap open android
```
